# Team Calculator Using Git

## 1. Project Description

The Team Calculator is a simple calculator application developed using the C programming language. This project demonstrates collaborative software development using Git and GitHub.

## 2. Project Objectives

- To develop a calculator using C.
- To understand Git version control.
- To learn how to create and manage branches.
- To collaborate with multiple team members.
- To understand Pull Requests and merging.

## 3. Features

The calculator performs four basic arithmetic operations:

1. Addition
2. Subtraction
3. Multiplication
4. Division

## 4. Team Contributions

| Team Member | Contribution |
|---|---|
| Member 1 | Addition |
| Member 2 | Subtraction |
| Member 3 | Multiplication |
| Member 4 | Division |

## 5. Technologies Used

- C Programming Language
- Git
- GitHub
- Visual Studio Code

## 6. Git Concepts Used

- Repository creation
- Branch creation
- Adding and committing files
- Pushing changes to GitHub
- Pull Requests
- Branch merging
- Merge conflict handling (if demonstrated)

## 7. Project Files

- main.c – Main calculator program
- add.c – Addition function
- subtract.c – Subtraction function
- multiply.c – Multiplication function
- divide.c – Division function
- calculator.h – Function declarations

## 8. Compilation Instructions

Compile the project using:

```bash
gcc main.c add.c subtract.c multiply.c divide.c -o calculator
```

## 9. Execution Instructions

Run the calculator using:

```bash
./calculator
```

## 10. Conclusion

This project helped us understand teamwork, C programming, Git version control, and collaborative development using GitHub. All four calculator functions were integrated into the main branch.
